# Jeu d'animation "Secret story"

Mise en place et suivi pour le jeu d'animation sur le thème de "Secret story"

# Prérequis

- node (>= 22)
- npm
- cloner le projet

# Outils du projet

- Vite
- Vue.js
- Pinia
- Vue Router
- Milligram CSS
- Linter et formatter : Eslint, Prettier

# Installation

```bash
npm install
```

# Lancer le projet

```bash
npm run dev
```
